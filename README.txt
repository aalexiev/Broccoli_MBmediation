These are the files in this directory:

Input and output directories for files and figs/tables going in and out of 
various code

Prediction1_mediation is for the mediation analysis of diet -> asvs -> sfn

Enterotyping is the analysis of identifying and characterizing the 
different microbiome subtypes

Prediction2_mediation is for the mediation analysis of asvs/microbiome 
subtypes -> diet -> sfns; the flipped_mediation directory within this 
directory uses asvs as the X variable, whereas the rest of the directory 
pertains to code where microbiome subtype is used as the X variable

RandomForest is a directory for analyses looking at what asvs are related 
to SFN-NIT response

random_code has extra scripts and shortcuts for longer portions of code
